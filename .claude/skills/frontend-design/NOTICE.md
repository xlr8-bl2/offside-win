# Where this came from

`SKILL.md` in this directory is Anthropic's `frontend-design` skill, vendored
unmodified from the public skill library so that it travels with this
repository rather than depending on whatever happens to be installed on the
machine running Claude Code.

It is Apache 2.0 licensed; `LICENSE.txt` is the full text and stays with it.

It earned its place here. Its list of generated-design tells named two of the
three theme directions drafted for this site — a near-black ground with one
bright accent, and a broadsheet layout of hairline rules — before either got
as far as code. The live site at the time was committing four more from the
same list: all-caps eyebrow labels above every heading, meta strings joined
with middle dots, a tinted near-black standing in for black, and an arrow
appended to link text. All four have since been removed.

Check for a newer version at /mnt/skills/public/frontend-design/ or in the
Claude Code skill library before assuming this copy is current.
